# LIT Buy — Documentation index

This index answers two questions for an external reviewer: **what should I read first, and what must not be treated as current implementation status?** The Claude Code read-only audit has been completed over the immutable **AUDIT BASELINE** `b88e6efdc252dc9eb6afd3d90375dc3d454ce72d`. A later **POST-AUDIT REMEDIATION HEAD** is only the current `main` HEAD after remediation PRs and never changes the audited snapshot.

## Authority rules

1. **GitHub remoto** é a autoridade para branch, HEAD, código, PR, diff, CI e merge; nenhum snapshot documental substitui estado remoto posterior.
2. [`ALPHA_SCOPE_AND_COMPLETION_CHECKLIST.md`](./ALPHA_SCOPE_AND_COMPLETION_CHECKLIST.md) tem maior autoridade para escopo funcional do Handoff Alpha, inclusões deliberadas, feature freeze e limites funcionais. `PENDENTE DE IMPLEMENTAÇÃO ALPHA = 0` não prova browser E2E, segurança, ausência de findings, staging ou produção.
3. [`CLAUDE_AUDIT_FINDINGS_LEDGER.md`](./CLAUDE_AUDIT_FINDINGS_LEDGER.md) é a maior autoridade pós-auditoria para IDs, severidade final, adendos, disposição, status e evidência de fix.
4. [`POST_AUDIT_REMEDIATION_PLAN.md`](./POST_AUDIT_REMEDIATION_PLAN.md) é a autoridade para ordem, workflow, gates, divisão Codex/humano e fechamento pós-auditoria.
5. [`CHECKPOINT_MESTRE_POS_AUDITORIA_CLAUDE_2026-08-13.md`](./CHECKPOINT_MESTRE_POS_AUDITORIA_CLAUDE_2026-08-13.md) é o snapshot de transferência/contexto do corte e não substitui estado GitHub posterior.
6. Referências de domínio definem contratos/evidências mais estreitos; documentos históricos não prevalecem sobre as autoridades atuais. Planejamento não prova implementação.
